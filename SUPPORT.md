# Support

PROOF is an early-stage open source project. Community support is best-effort, and no response-time or compatibility guarantee is currently offered.

Before requesting help:

1. Check the README, project documentation, and existing issues.
2. Confirm that the problem occurs on a current supported revision.
3. Reduce the problem to the smallest reproducible example you can share safely.

Use the public issue tracker for reproducible bugs and feature requests. Include the relevant version or commit, environment, input, expected behavior, actual behavior, and reproduction steps. Use GitHub Discussions for usage questions when Discussions are enabled.

Keep each request focused and remove secrets, credentials, proprietary specifications, and personal data before posting.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must never be reported publicly. Conduct concerns should follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
